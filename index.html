strays
a tiny team of debugging pets.

Four pets wandering along the bottom of your screen while Claude Code works. Each one is a bug you have personally met. They are all very low-maintenance. None of them can be fixed.

Segfaultcat

Everything's fine, everything's fine, then SIGSEGV. Crashes for no discernible reason, dumps core on your floor, respawns elsewhere like nothing happened. You reconstruct what happened from the aftermath.

Grepdog

Finds everything, including things you didn't ask it to find. Digs up Segfault's core dumps, your .env.production, and a tennis ball. Recursive by default. No known way to make him stop.

Mutexcat

Two cats can never pass each other without lock contention. When Mutex and Segfault meet, both freeze — 🔒 — until the scheduler preempts one at random. The loser walks away insisting this isn't over.

Heisenbugfish

A fish in a space helmet, like the kid in Wonder. No tank — she just floats by. Only misbehaves when you're not looking: stop moving your mouse and the anomaly counter climbs. Look back — "cannot reproduce."

Desktop features — what the overlay does with Claude Code

💭🔧❗✓ live states     each session gets a pet; a badge shows thinking /
                 running a tool / waiting on you / done
❗       needs-you       a blocked session makes its pet hop until you look
👆      tap to jump     click a pet, land on that pet's session — the exact
                 conversation, not just the app (macOS)
✅      Allow / Deny    when Claude Code would really stop and ask, a card
                 rises over the pets; click Allow, never switch
                 windows (npm run hooks). In auto mode nothing asks,
                 so nothing appears — that's it working.

Install — the whole point is that this takes a minute

# on your desktop, as an overlay above every window (macOS):
git clone https://github.com/tisu19021997/strays && cd strays/desktop
npm install && npm start

# or on any web page, one script tag:
<script src="strays.js" data-auto data-party></script>

THE COMMISSION
“If I had a pet, I'd probably go with something like Segfault — a cat, obviously. Cats already behave like segfaults: everything's fine, everything's fine, then suddenly they crash through something for no discernible reason and leave you to reconstruct what happened from the aftermath.”
Tip: hover a pet for its status card. Pet the cats (click). Throw nothing — Grep already has the ball, and there is only one ball. Watch the fish, then don't, and check the anomaly counter.

Open source, MIT. Pets you draw in the editor join the team automatically — PRs with new species welcome.
